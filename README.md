# Sustainable Living Quality Index (SLQI)

## Project Overview

This project develops a **Sustainable Living Quality Index (SLQI)** to compare countries based on multiple indicators related to living quality and sustainability.

The SLQI is a composite index built from five main dimensions:

- Economic conditions
- Health and education
- Infrastructure
- Governance
- Environment

The purpose of the project is to create a clear and explainable country-level index. The final result provides an SLQI score and rank for each country included in the cleaned dataset.

This project was completed as part of a Data Visualisation and Analytics assessment.

---

## Aim of the Project

The main aim of this project is to build a composite index that can help compare sustainable living quality across countries.

Instead of relying on a single indicator, such as GDP per capita, this project combines several indicators into one index. This gives a broader view of living quality because sustainability depends on economic, social, environmental, infrastructure, and governance factors.
